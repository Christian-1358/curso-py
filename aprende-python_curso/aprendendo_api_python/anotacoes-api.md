# O QUE É UMA API      
API em Python:

Uma API é uma ferramenta que permite que um programa se comunique com outro sistema para obter ou enviar informações.

Requisição: 

É uma solicitação que um programa envia para uma API, pedindo informações ou realizando alguma ação.

Exemplo: Um programa em Python faz uma requisição a uma API de clima para obter a temperatura atual de uma cidade.
